# Python EDA Project

## Project Overview
This project performs Exploratory Data Analysis (EDA) using Python and Pandas to understand sales data and identify useful insights.

## Technologies Used
- Python
- Pandas
- Matplotlib
- VS Code
- Power BI

## Project Features
- Data loading and exploration
- Summary statistics
- Sales analysis by product and region
- Data visualization using charts
- Export of cleaned data for Power BI

## How to Run
1. Install Python.
2. Install the required libraries:
   `pip install pandas matplotlib`
3. Run the Python file:
   `python eda_report.py`
